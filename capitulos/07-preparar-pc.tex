\chapter{Preparar el computador}\label{cap:pc}

Esto se hace una sola vez por computador. Las instrucciones son para Windows 10 u 11; en macOS y Linux los programas son los mismos.

Comprueba cada instalación en una terminal nueva (PowerShell):
\begin{comando}
git --version
node --version
esptool version
\end{comando}
Cada comando debe responder con un número de versión.

\section{Obtener el código}

El código del proyecto se entrega en GitHub: la app LUMA y esta documentación en sus repositorios, y WLED desde su repositorio oficial en la versión exacta que se probó.

\pendiente{repositorioApp}{Dirección del repositorio de GitHub donde se entrega LUMA (y de esta documentación). Mientras tanto se escribe \texttt{<repositorio-luma>}.}

\begin{comando}
mkdir C:\Proyectos\LUMA
cd C:\Proyectos\LUMA
git clone <repositorio-luma> luma-app
git clone https://github.com/wled/WLED.git WLED
cd WLED
git checkout 961961fd
\end{comando}

\nota{\texttt{git checkout \dato{wledCommit}} fija WLED en la versión \dato{wledVersion} que se probó en el poste. No actualices WLED a otra versión sin repetir la prueba de aceptación completa (capítulo~\ref{cap:aceptacion}).}

La estructura que debe quedar es:
\begin{comando}
C:\Proyectos\LUMA\
    luma-app\        la aplicación LUMA
    WLED\            el firmware
    documentacion\   este manual (opcional)
\end{comando}

Instala las dependencias de LUMA una vez:
\begin{comando}
cd C:\Proyectos\LUMA\luma-app
npm install
\end{comando}

\section{Reconocer el puerto USB de la ESP32}

\begin{enumerate}
\item Desconecta los 12~V de la placa (ver la advertencia del capítulo~\ref{cap:grabar}).
\item Conecta la ESP32-S3 al computador con un cable USB-C de datos (algunos cables solo cargan).
\item Abre el Administrador de dispositivos › Puertos (COM y LPT). Debe aparecer un puerto nuevo, por ejemplo \texttt{COM5}.
\item Si no aparece, prueba el otro conector USB-C de la placa. Si sigue sin aparecer, instala el driver del chip USB-serie que lleva la placa (CH340/CH343 de WCH o CP210x de Silicon Labs, según la placa).
\end{enumerate}
